# Kidmans Partners — Functional Service Finder

This folder contains the interactive Business and Personal Service Finder wireframe and its developer build specification.

- `index.html` — Functional wireframe: both landing pages, 75 outcome combinations, nine unstyled Gravity Forms notification previews, and developer logic.
- `BUILD_SPEC.md` — Field map, conditional logic, outcome routes, static service tiers, and Gravity Forms implementation instructions.
