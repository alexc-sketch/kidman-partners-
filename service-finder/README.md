# Kidmans Partners — Functional Service Finder

This folder contains the interactive Business and Personal Service Finder wireframe and its developer build specification.

- `index.html` — Starts with a developer dashboard/menu, then provides both landing pages, 75 outcome combinations, nine unstyled Gravity Forms notification previews, and developer logic. The detailed tab navigation remains available throughout.
- `build-guide.html` — Accessible visual build guide with short instructions, form flows, answer maps, outcome-page anatomy, email configuration and QA checks. Start here for implementation.
- `BUILD_SPEC.md` — Copyable technical reference: field map, conditional logic, outcome routes, static service tiers, and Gravity Forms implementation instructions.
